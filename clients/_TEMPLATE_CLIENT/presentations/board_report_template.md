# Board Report Template

**Period:**

## Executive summary
3 bullets max — what the board needs to know.

## KPI dashboard
Pull from `agency-assets/_master-templates/universal_reporting_dashboard_template.md` structure, condensed to board-relevant metrics only (usually revenue-adjacent: pipeline, CAC, LTV, growth rate).

## Strategic context
How marketing performance ties to broader company goals this period.

## Risks/asks
Anything the board needs to weigh in on or unblock.

## Accuracy note
Board-level numbers get extra scrutiny before this ships — verify against source data directly, don't propagate a number from a prior report without re-checking it.
