# Services/Products Page Blueprint

## Per-offering section
- Name
- One-line value prop
- Key features/benefits (3-5)
- Pricing (if public) — verify current pricing with client before publishing, never assume last quarter's numbers hold
- CTA (demo, buy, contact sales — depends on funnel stage)

## Cross-sell/upsell
Where relevant, link between related offerings from `_context/client_product_offerings.md`.

## Proof
Link case studies/testimonials specific to each offering where available.
