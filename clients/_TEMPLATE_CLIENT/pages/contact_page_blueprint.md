# Contact Page Blueprint

## Elements
- Contact form (minimal required fields)
- Direct contact info (email/phone) if the client wants it public
- Physical address if applicable (required for CAN-SPAM compliance on email footers regardless)
- Response time expectation set honestly (don't promise "instant" if it's not true)
- Map embed if there's a physical location

## Form handling
Where do submissions route (CRM integration via HubSpot MCP, direct email)? Confirm with client and test the full submission path before launch.

## Spam prevention
CAPTCHA or equivalent — note per the agency's action policy, CAPTCHAs are never bypassed/solved by automation; this is about preventing spam submissions, not about agency tooling interacting with the form itself.
