# Landing Page Blueprint

See `_templates/landing_page_template.md` for the copy-level template. This doc is the structural/UX blueprint reused across campaigns.

## Standard sections
1. Hero (headline, subhead, primary CTA, hero image/video)
2. Trust signals (logos, review scores, stats)
3. Value props (3, each with icon + 1-2 sentences)
4. How it works / product walkthrough
5. Testimonials/case study snippet
6. FAQ (address top 3-5 objections)
7. Final CTA with urgency/reinforcement

## Technical requirements
- Page speed target: (e.g. LCP < 2.5s)
- Mobile-first design
- Form fields: minimize to what's actually needed for lead qualification

## Conversion tracking
Define the conversion event before build starts, not after launch.
