# Advertising SOP (Client)

## Trigger
New paid campaign or ongoing paid media management retainer.

## Steps
1. Confirm budget, flight dates, and target CPA/ROAS with client in writing before spend begins.
2. Build creative per `ads/ad_creative_brief.md` and `content_creation_sop.md`.
3. Set up campaigns in-platform (Google Ads MCP tools, or manually if that tool isn't enabled for this client — see `agency-assets/mcp-configurations/advertising-mcp-setup.md`).
4. **Any budget increase, bid strategy change, or campaign pause/resume affecting live spend requires explicit confirmation for that specific change** — this applies whether a human or an MCP tool is proposing it.
5. Monitor daily for the first week of any new campaign, weekly thereafter.
6. Report performance per `reporting_sop.md` cadence.

## Guardrails
- Set a hard daily budget cap in-platform as a backstop, independent of any automation.
- Never let an automated optimization loop run unattended on live client spend without a periodic human review checkpoint.
