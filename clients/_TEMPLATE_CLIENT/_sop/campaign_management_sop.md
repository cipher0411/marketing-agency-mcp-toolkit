# Campaign Management SOP (Client)

## Trigger
New campaign brief approved.

## Steps
1. Define objective, audience, budget, timeline in `_master-templates/universal_project_brief_template.md`.
2. Build creative (see `content_creation_sop.md`, `ads/ad_creative_brief.md`).
3. Set up tracking (UTM parameters, conversion events) before launch — never launch without measurement in place.
4. Launch only after `brand_approval_sop.md` sign-off and, for paid campaigns, explicit client confirmation of budget.
5. Monitor performance against target daily for the first week, then per the cadence in `advertising_sop.md`.
6. Optimize (bid/budget/creative changes) — log every change and its rationale; any budget change above the pre-agreed threshold requires client confirmation.
7. Post-campaign: `reports/campaign_post_mortem_template.md`.

## Pause/kill criteria
Define upfront: what performance threshold triggers pausing a campaign for review (e.g. CPA 2x target sustained for 3 days).
