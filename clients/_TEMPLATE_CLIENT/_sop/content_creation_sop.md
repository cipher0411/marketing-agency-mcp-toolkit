# Content Creation SOP (Client)

## Trigger
Content calendar item due, or ad hoc request via project brief.

## Steps
1. Fill `_master-templates/universal_project_brief_template.md` for the piece.
2. Ideation: `fetch_trends` (Social Neuron) or manual research against `_context/client_growth_marketing_context.md`.
3. Draft using the relevant `_templates/` file, matching `_context/client_brand_voice_guide.md`.
4. If using AI generation (Lamina/Social Neuron), load brand context first (`brand_lookup` / `get_brand_profile`) so output is on-brand from the start.
5. Run `quality_check` (Social Neuron) or manual QA per `agency-assets/_global-sops/quality_assurance_sop.md`.
6. Submit for client approval per `brand_approval_sop.md`.
7. Schedule/publish only after explicit approval.

## Outputs
Filed in the relevant folder (`social/`, `pages/`, etc.) plus logged in the content calendar.
