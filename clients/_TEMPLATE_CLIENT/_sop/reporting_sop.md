# Reporting SOP (Client)

## Cadence
- Weekly: async update (see `agency-assets/_global-sops/client_communication_sop.md`)
- Monthly: full report call using `reports/monthly_report_template.md`
- Quarterly: strategy review using `reports/quarterly_report_template.md`

## Data collection
Pull from GA4, Ahrefs, HubSpot, Social Neuron, Google Ads per `agency-assets/mcp-configurations/analytics-mcp-setup.md`. Cross-check numbers across tools before presenting — see `reports/mcp_analytics_workflows.md`.

## Report structure
Follow `agency-assets/_master-templates/universal_reporting_dashboard_template.md`.

## Sign-off
Reports get an internal QA pass (numbers double-checked, narrative matches data) before going to the client — a wrong number in a client report is a trust problem, not just a formatting error.
