## Data source
Pull via Google Ads MCP tools (`agency-assets/mcp-configurations/advertising-mcp-setup.md`) or manual export if that tool isn't enabled for this client. Cross-check platform-reported conversions against GA4/HubSpot — attribution windows often differ and cause apparent discrepancies that aren't actually errors.

## Review cadence
Weekly for active campaigns, per `_sop/advertising_sop.md`.
