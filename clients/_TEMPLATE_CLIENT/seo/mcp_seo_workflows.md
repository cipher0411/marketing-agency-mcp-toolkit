# MCP SEO Workflows (Client)

See `agency-assets/mcp-configurations/analytics-mcp-setup.md` for current Ahrefs setup guidance (Ahrefs recommends their remote MCP over the local `@ahrefs/mcp` package as of the last verification pass).

## Keyword research
1. Ahrefs keyword tools → populate `keyword_research_template.md`.
2. Cross-check search intent manually — tool-reported intent classification isn't always right for niche/technical terms.

## Rank tracking
1. Ahrefs rank tracking, monthly pull.
2. Log into `seo_strategy_template.md` and `reports/monthly_report_template.md`.

## Competitive/backlink analysis
1. Site Explorer for competitor organic footprint (feeds `research/competitor_analysis_template.md`).
2. Backlink monitoring (feeds `off_page_seo_guide.md`).

## Brand monitoring
1. Brand Radar for AI/web brand mentions — flag anything requiring a response per `_global-sops/client_communication_sop.md`.

## Cost note
Ahrefs is a flat subscription ($129-$449/mo), not pay-per-call — confirm this client's retainer covers Ahrefs access before promising deliverables that depend on it.
