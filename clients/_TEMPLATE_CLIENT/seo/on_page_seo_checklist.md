# On-Page SEO Checklist

- [ ] Target keyword in title tag, ideally near the front
- [ ] Meta description written (not auto-generated, compelling, ≤155 chars)
- [ ] One H1, logical H2/H3 hierarchy
- [ ] Target keyword in first 100 words naturally
- [ ] Internal links to/from relevant pages
- [ ] Image alt text descriptive, not keyword-stuffed
- [ ] URL slug short and keyword-relevant
- [ ] Mobile rendering checked
- [ ] Page speed acceptable (Core Web Vitals)
- [ ] Schema markup added where applicable (Article, Product, FAQ, etc.)
- [ ] No duplicate title/meta across pages
