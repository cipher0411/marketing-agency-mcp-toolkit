# Off-Page SEO Guide

## Link building
- Only pursue links from relevant, reputable sites — no link farms or purchased links that violate search engine guidelines.
- Tactics: digital PR, guest posts (genuine contribution, not spun content), resource page outreach, unlinked mention reclamation.

## Monitoring
Track new/lost backlinks via Ahrefs (`agency-assets/mcp-configurations/analytics-mcp-setup.md`). Disavow toxic links only after careful review — over-disavowing can hurt more than it helps.

## Brand mentions
Ahrefs Brand Radar tracks AI/web brand mentions — use for digital PR opportunity spotting and reputation monitoring.

## Reporting
Monthly backlink profile summary feeds into `reports/monthly_report_template.md`.
