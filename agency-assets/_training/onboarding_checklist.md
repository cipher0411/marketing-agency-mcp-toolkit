# New Hire Onboarding Checklist

## Week 1
- [ ] Access to shared drive / this folder structure
- [ ] Read `README.md` and `MCP_VERIFICATION_REPORT.md`
- [ ] Read all `_global-sops/` docs
- [ ] Access to Slack, Notion
- [ ] Shadow one client call

## Week 2
- [ ] Read one existing client's `_context/` folder end to end
- [ ] Complete a practice deliverable using `_master-templates/`, get it reviewed via `quality_assurance_sop.md`
- [ ] Get MCP credentials issued for the tools relevant to their role (per `mcp-credentials-management.md` — least-privilege, not blanket access)

## Week 3–4
- [ ] Own a small real deliverable for an active client, under review
- [ ] Complete `training_curriculum.md`

## Ongoing
- [ ] Know where to escalate (see relevant SOP) before taking any irreversible action (sending, publishing, spending budget) on a client's behalf
