# Training Curriculum

## Module 1: Agency operating model
- Folder structure walkthrough
- SOP index and when each applies

## Module 2: Client fundamentals
- How to read a `_context/` folder
- Brand voice matching exercise

## Module 3: MCP tools for your function
- Content roles: `content-mcp-setup.md`, `social-mcp-setup.md`
- Growth/lead-gen roles: `leadgen-mcp-setup.md`
- Analytics/SEO roles: `analytics-mcp-setup.md`
- Paid media roles: `advertising-mcp-setup.md`

## Module 4: Security & judgment
- `mcp_security_sop.md` in full
- Why unverified tool names matter (walk through `MCP_VERIFICATION_REPORT.md` as a case study)
- When to escalate vs. when to proceed

## Module 5: Quality bar
- `quality_assurance_sop.md`
- Review 3 past client deliverables with a mentor, discuss what made them pass/fail QA

## Assessment
New hire produces one full deliverable (brief → draft → QA → approval) shadowed by a mentor before working unsupervised on live client work.
