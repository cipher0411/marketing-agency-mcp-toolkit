# Universal Project Brief Template

Fill out before starting any new deliverable (campaign, content piece, landing page, etc.) so scope is explicit before work begins.

## Project name
## Client
## Requested by / date
## Objective
What business outcome is this for? (Not "write a blog post" — "generate 20 MQLs from the enterprise segment.")

## Audience
Who is this for? Reference the client's ICP/persona docs if they exist.

## Deliverable(s)
Specific format, length, channel.

## Key message
The one thing the audience should take away.

## Brand/voice constraints
Link to `_context/client_brand_voice_guide.md`.

## Success metric
How will we know this worked? Tie to a number where possible.

## Timeline
- Draft due:
- Review due:
- Ship date:

## Approval required from
(name/role — see `_sop/brand_approval_sop.md`)

## Budget / tool cost
If this uses a pay-per-call MCP tool (Forage, Apify actors), estimate cost upfront and note it here.
