# Recommended Tools List

## MCP-integrated (see `mcp-configurations/` for setup)
- Lead gen/enrichment: Apollo.io, Hunter.io, b2b-enrichment-mcp, Forage MCP
- Content/creative: Social Neuron, Lamina, Canva
- CRM/automation: HubSpot, Klaviyo
- Analytics/SEO: Google Analytics, Ahrefs, Google Sheets
- Advertising: Google Ads (community MCP — see caveats in `mcp-configurations/advertising-mcp-setup.md`)
- Collaboration: Notion, Slack

## Non-MCP tools worth having (evaluate before adopting)
- Design fallback if Canva/Lamina aren't licensed for a client: Figma
- Video editing fallback: CapCut or Premiere for anything beyond what Social Neuron/Lamina auto-generate
- Password/secrets manager: required — do not store client API keys in plaintext docs, ever

## Selection criteria
Before adding a new tool to this list: is it solving a real recurring need, does it have a legitimate publisher/maintainer, and does its cost model fit the client tiers we actually serve? Don't add a tool because it's trendy — check `mcp_tool_reference.md` for the standard the agency holds new tools to.
