## Non-MCP tool setup
Document manual tool setups (design software, project management, etc.) here as they're adopted. Follow the same standard as MCP tools: confirm the tool/vendor is legitimate before an account is created or payment info is entered, and never enter payment credentials without the actual account holder's involvement.
