# Logo Usage Guide (Agency)

## Fill in per actual logo files
- Primary logo: (file path/location)
- Minimum clear space: (e.g. equal to the height of the logomark on all sides)
- Minimum size: (px/pt for digital and print)
- Approved color variants: full color / white / black
- Backgrounds it may sit on (and which to avoid — e.g. never on a busy photo without a scrim)

## Don't
- Stretch or skew
- Recolor outside approved variants
- Add drop shadows/effects not in the original file
- Rotate
- Place on a background that fails contrast requirements
