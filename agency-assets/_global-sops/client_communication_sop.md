# Client Communication SOP

**Owner:** Account lead per client
**Applies to:** All client-facing communication

## Cadence
- Weekly async update (Slack or email) — 3 bullets: what shipped, what's next, any blockers.
- Monthly report call — walk through `reports/monthly_report_template.md`.
- Quarterly strategy review — walk through `reports/quarterly_report_template.md`.

## Rules
1. Never send a client-facing message, report, or asset without it passing `_sop/brand_approval_sop.md` first.
2. Bad news (missed target, tracking broken, campaign underperforming) gets flagged proactively, same week it's discovered — not saved for the monthly report.
3. Any message sent on the client's behalf (e.g. via a connected email/Slack MCP tool) requires explicit confirmation before sending — treat this the same as any other irreversible send action.
4. Keep a single source of truth for decisions (client folder, not scattered email threads) — link back to the relevant doc when a decision is referenced later.

## Escalation triggers
- Client expresses dissatisfaction → account lead within 24h
- Scope creep request → account lead reviews against contract before agreeing
- Tool/data access revoked unexpectedly → flag immediately, don't assume it's a mistake
