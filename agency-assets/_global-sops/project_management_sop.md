# Project Management SOP

**Owner:** Account lead
**Applies to:** All ongoing client work

## Structure
- Each client has a running project brief log (`_master-templates/universal_project_brief_template.md` copies) for active deliverables.
- Weekly internal sync per client: status of in-flight work, blockers, upcoming deadlines.

## Prioritization
1. Client-committed deadlines (contractual)
2. Time-sensitive opportunities (trending topic, seasonal campaign window)
3. Ongoing retainer work (content calendar, SEO maintenance)
4. Internal process improvement

## Tool coordination
- Notion or the client folder structure is the source of truth for deliverable status — not scattered Slack threads.
- If a deliverable depends on an MCP tool this client doesn't have enabled, flag to account lead before committing to a timeline that assumes it.

## Handoff
When a team member rotates off a client, they document open items, tool access they held, and any in-flight approvals in the client's `_sop/` folder before leaving.
